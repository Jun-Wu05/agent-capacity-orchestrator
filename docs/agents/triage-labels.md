# Triage Labels

各 skills 使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义                                  |
| ---------------------------- | ------------------------- | ------------------------------------- |
| `needs-triage`               | `needs-triage`            | 需要维护者评估该 issue                |
| `needs-info`                 | `needs-info`              | 等待报告者补充信息                    |
| `ready-for-agent`            | `ready-for-agent`         | 已完整说明，可交给无人值守 agent 执行 |
| `ready-for-human`            | `ready-for-human`         | 需要人工实现                          |
| `wontfix`                    | `wontfix`                 | 不会处理                              |

当某个 skill 提到某个角色（例如"打上 AFK-ready triage label"）时，使用上表中对应的 label 字符串。

如果实际使用的词汇不同，直接修改右侧那一列。
